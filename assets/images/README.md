Положите сюда файлы иконок:

- `launcher_icon.png` — иконка лаунчера в левом столбце на ПК и для общего значка приложения.
- `boosty_icon.png` — иконка Boosty.
- `telegram_icon.png` — иконка Telegram.
- `cover.jpg` (или `cover.png`) — обложка игры.

Рекомендуемый размер для всех иконок: 512x512 px, PNG, квадрат 1:1.
Минимально допустимо: 256x256 px, но 512x512 px лучше для резкости на всех экранах.
Для лаунчера и социальных иконок лучше использовать прозрачный фон и округлённый/квадратный рисунок без белых полей.

Если файла нет, в интерфейсе автоматически показывается запасная иконка/заглушка.
