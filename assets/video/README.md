# Анимированные обложки

Положите сюда анимированные файлы обложек — выбранная в настройках обложка
будет проигрываться в hero-секции, если включён тумблер «Анимированная обложка».

Поддерживаемые форматы:

- `.mp4` — видео (**только Android**, проигрывается через `video_player`).
- `.webp` — анимированный WebP (рекомендуется на десктопе; лучший баланс
  качества/размера).
- `.gif` — анимированный GIF.

## Варианты обложек

В настройках доступно 7 вариантов. Для каждого используйте свои файлы:

- Обложка 1 → `cover1.mp4` / `cover1.webp` / `cover1.gif`
- Обложка 2 → `cover2.mp4` / `cover2.webp` / `cover2.gif`
- Обложка 3 → `cover3.mp4` / `cover3.webp` / `cover3.gif`
- Обложка 4 → `cover4.mp4` / `cover4.webp` / `cover4.gif`
- Обложка 5 → `cover5.mp4` / `cover5.webp` / `cover5.gif`
- Обложка 6 → `cover6.mp4` / `cover6.webp` / `cover6.gif`
- Обложка 7 → `cover7.mp4` / `cover7.webp` / `cover7.gif`

Порядок выбора файла:
- На **Android** сначала пробуется `.mp4` (через video_player), затем
  `.webp`, затем `.gif`.
- На остальных платформах — `.webp`, затем `.gif`.

Если для выбранного варианта нет ни одного файла — используется статичная
обложка `assets/images/cover.jpg`.

Рекомендации:
- Соотношение сторон близкое к обложке (примерно 16:9), разрешение до ~1280×720.
- Зацикленная анимация без резких склеек.
